# RPG Stats Mod

Enhance your Minecraft experience with an RPG UI and player stats system.

## Features

- RPG UI with player levels and stats
- Customizable stats: Health, Strength, Agility, and Luck
- Stat points system for leveling up
- Item requirements based on player stats

## Requirements

- Minecraft 1.20.1
- Forge 40.2.0

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with Forge.

## Usage

1. Open the RPG UI to view and manage your stats.
2. Use stat points to increase your stats.
3. Equip items that require specific stats.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
